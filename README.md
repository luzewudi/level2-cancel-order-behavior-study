# level2-cancel-order-behavior-study

对于《20240124-开源证券-市场微观结构研究系列（22）：订单流系列，撤单行为规律初探》的复现与扩展。

## 项目结构

- `草稿/撤单/config.py`: 全局路径、日期范围和算法撤单识别参数配置
- `草稿/撤单/step1_数据处理.py`: Level-2 原始逐笔数据到撤单分钟因子的处理脚本
- `草稿/撤单/step2_因子计算.py`: 后续因子计算脚本
- `utils/`: 路径、日志、绘图和配色工具

## 本地数据

原始行情数据、日频 numpy 数据、parquet/pkl 输出和临时目录默认不纳入 Git 管理。运行前请在 `草稿/撤单/config.py` 中按本机环境调整数据路径。
